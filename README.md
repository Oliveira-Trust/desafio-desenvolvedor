# Desafio Backend – API de Upload

API desenvolvida em Laravel para upload e consulta de arquivos CSV/XLSX.

## Funcionalidades
- Upload de arquivos com validação de formato
- Prevenção de upload duplicado
- Histórico de uploads com filtros

## Endpoints
- GET /api/health
- POST /api/uploads
- GET /api/uploads

## Tecnologias utilizadas no projeto
- PHP 8+
- Composer
- Laravel
